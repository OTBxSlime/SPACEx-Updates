# SPACEx Updates

In Lexis, open SPACEx Settings > Updates > Check for Updates, then reload the script when prompted.

The mouse edition includes animated blue nebula frames and extracts them automatically when needed. No separate animation download is required. Existing personal settings are preserved. The controller release is unchanged.

Known issue: live protection crashes remain under investigation; the model guard remains disabled.
